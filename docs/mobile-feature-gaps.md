# 移动端功能差异清单

基于上游源码 `ec3964ab`（2026-10-17）的功能审计；上一轮基线为上游 `83ab712` / 移动端 `3ef92d2`。翻译 key 是否引用只能作为查找线索，不代表功能覆盖率。

## 本轮补齐（上游 ec3964ab）

- 镜像同步：`types.ts` 与四语文案；上游为大写错误码单独提供了文案（如 `PLAYER_ACCESS_CLOSED`）。
- CoC 孤注一掷：检定卡内申请 / 告知风险 / 拒绝 / 确认重掷 / 接受失败，待决项阻断行动输入。
- 剧情「角色对话」模式：`LogEntry.story` 旁白卡 + 说话人台词气泡（逐条朗读），SSE `story_update` 流式快照。
- 本局偏好（GM）：孤注一掷开关、默认显示快捷建议、骰子揭示方式、剧情表现；玩家可按对局 + 角色独立隐藏建议。
- CoC 奖励/惩罚骰明细：共享个位、十位组合与采用项。
- 行动提交失败恢复：已回滚可改后重发；已入账/结果不确定先刷新核对，已入账的行动刷新后清空草稿。

## 上一轮补齐

- 桌外 GM/KP 问答：默认私密、可共享全队，独立问答记录入口，不占用行动或回合日志；重连补拉共享记录。
- 对局内叙事视角：GM 可在桌面管理 → 设置中切换自动、沉浸、第三人称。
- 幸运决议超时：独立保存 0–3600 秒，空白不改，0 禁用超时；房间密码保持独立设置。
- 记忆分页：每页 50 条、总量/页码、上一页/下一页、点击当前页码打开选择器（支持输入定位）、搜索重置、删除末页后的页码调整；页码控件支持键盘避让及范围校验。
- 通用 query：`api` 和 `apiBlob` 接受 `query` 对象，统一编码、省略 null/undefined、保留 0/false/显式空字符串；身份参数由 client 注入。分页上限等业务限制仍归资源接口负责。
