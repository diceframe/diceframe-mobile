# 移动端功能差异清单

基于上游源码 `83ab712` 与移动端基线 `3ef92d2` 的功能审计。翻译 key 是否引用只能作为查找线索，不代表功能覆盖率。

## 本轮补齐

- 桌外 GM/KP 问答：默认私密、可共享全队，独立问答记录入口，不占用行动或回合日志；重连补拉共享记录。
- 对局内叙事视角：GM 可在桌面管理 → 设置中切换自动、沉浸、第三人称。
- 幸运决议超时：独立保存 0–3600 秒，空白不改，0 禁用超时；房间密码保持独立设置。
- 记忆分页：每页 50 条、总量/页码、上一页/下一页、点击当前页码打开选择器（支持输入定位）、搜索重置、删除末页后的页码调整；页码控件支持键盘避让及范围校验。
- 通用 query：`api` 和 `apiBlob` 接受 `query` 对象，统一编码、省略 null/undefined、保留 0/false/显式空字符串；身份参数由 client 注入。分页上限等业务限制仍归资源接口负责。
